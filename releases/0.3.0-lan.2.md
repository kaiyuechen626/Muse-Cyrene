# Muse Cyrene 0.3.0-lan.2（273）

ARM64 预发布版，发行标签 `cyrene-v0.3.0-lan.2`。

## 更新

新增与 Muse Multi-Agent 0.3.0-lan.2 的加密局域网配对与自动同步。首次可选二维码或 USB，并在手机确认；后续同一局域网自动同步角色、文字聊天及事实记忆。两端独立创建的同名 AI 先询问合并或分别保留，保留选择会记住；合并统一身份、汇总聊天和记忆，不同设定留存副本，合并前保存原始资料。

手机本机有两份对应角色时，重复项保留为停用备份，聊天移到保留角色；只有一份时复用本机角色配置。密钥、模型服务配置、DSH 授权及语音模型保留本地。图片、文件附件及高级分支不作为跨端文件同步对象。

## 安装与验证

使用原签名覆盖升级，包名不变，版本代码从 271/272 升至 273，无需卸载。最终 APK 已安装到 Samsung S25，安装文件与交付文件哈希一致，首次安装时间保持不变。Release 构建、R8、资源压缩与 lintVital 通过；5 项隔离真机测试和 1 项直连 Wi-Fi 测试通过。配套电脑回归 81 项通过。

未自动确认正式角色的合并。本轮未执行全应用、全部语音、蓝牙、通话或 x86_64 真机回归。保留既有语音功能与许可材料，历史验收不充作本版新测试。

## 已知边界与附件

后台同步受 Android 调度、强制停止、省电和网络隔离影响。继承的 Junrar / ML Kit 许可疑问、完整运行时对应源码核对及图像库 16KB ELF 限制保持披露，见原核对记录。没有新增全面法律授权或全设备兼容承诺。
