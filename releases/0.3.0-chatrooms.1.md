# Muse Cyrene 0.3.0-chatrooms.1

发行标签：`cyrene-v0.3.0-chatrooms.1`，勾选 Pre-release。ARM64，versionCode 275，包名 io.zer0.muse.cyrene；本版为预发布。

升级前导出备份，使用同签名 APK 覆盖安装，不要卸载或清空数据。首次配对可扫码或 USB；手机私信、附件与群聊专用上下文保留在手机，见 docs/CHAT_ROOMS.md。

附件：ARM64 APK、当前源码 ZIP、SHA256SUMS.txt。源码保留许可、来源和固定运行时获取材料，排除个人状态、密钥、音色与模型。

本次构建和定向测试见 release/CURRENT_VALIDATION.json；历史手机验证单独标注，不代表本次重新验收。既有 Junrar/ML Kit 组合许可、运行时对应源码和图像库 ELF 16KB 限制仍保留，不宣称兼容全部设备。
