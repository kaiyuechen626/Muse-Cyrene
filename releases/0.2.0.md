# Muse Cyrene 0.2.0 — 手机本地音色朗读版（非官方修改版）

下载附件 **Muse-Cyrene-0.2.0-arm64-v8a.apk** 安装，约 104 MB。Android 8.0 以上 ARM64 手机可用，目标设备 Galaxy S25。

## 更新内容

- 导入 `.cyvoice` 角色包，在手机应用内合成语音，不要求额外 TTS 应用或云端 TTS。
- DeepSeek 回复完成后自动朗读；保留自动朗读开关、离开聊天后续读、暂停／继续／停止及系统 TTS 回退选项。
- 可选快速合成、按句分组、播放时预生成后续片段，减轻长文句间等待。
- 从 0.1.0 整理基线重建，保留已验收 0.1.9 的业务功能及原有网页、Node/npm/Python、OCR/RAR 等功能。

## 安装和数据

包名 io.zer0.muse.cyrene，版本 0.2.0（271）。与公开 0.1.0（261）、已验收 0.1.9（270）的签名一致，满足覆盖升级条件。先备份再覆盖安装；签名冲突时不要卸载或清除数据。已有聊天和音色按原存储保留。

APK 不包含语音模型、个人音色、参考录音或 API 密钥。已有应用内音色继续使用；新用户需导入有权使用的完整 `.cyvoice` 音色包。设置入口为“媒体／语音播报 → Cyrene 离线角色音色”。DeepSeek 对话仍需网络和用户自己的配置，本地语音无需联网合成。

## 已有验收与本次检查

Galaxy S25 上的 0.1.9 已完成保留数据升级及聊天、原昔涟音色、播放、暂停／继续、后台续读等用户验收。0.2.0 业务代码保持一致，复用该功能基线；最终 0.2.0 APK 未再次实机安装。Release 构建、27 项选定单元测试、lintVital、签名、升级版本、资源及 JNI 回调检查通过；并非全量测试或全部设备通过。

## 已知限制与许可说明

长文仍可能等待，后台新回复不保证自动启动朗读。蓝牙、电话打断、x86_64 及全应用回归不在本次验收范围。原 NDJSON 导入问题未修改。继承的 libimage_processing_util_jni.so 不满足 16KB ELF 对齐，不能宣称支持所有 16KB 页面设备；ZIP 对齐检查通过不等于全部原生库兼容。
