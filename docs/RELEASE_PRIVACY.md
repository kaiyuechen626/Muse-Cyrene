# 网络与个人数据说明

应用内离线角色模式在手机上完成合成和播放，不将待朗读文本或音频发送给云端 TTS。用户导入的参考录音、原文与音色模型由手机存储，公开源码和本地候选 APK 不附带这些个人数据。

DeepSeek 和其他用户配置的在线供应商仍需要网络，并按所选服务发送请求；这里的“离线语音”不表示聊天功能可以断网生成回复。原有其他语音引擎、工具和服务行为仍取决于用户选择。

现有 ML Kit OCR/条码 SDK 在设备处理图像，但按其[官方说明](https://developers.google.com/ml-kit/terms)可能联系 Google 获取更新/兼容信息并发送性能与用量指标。需要在正式分发前完成适用用户告知；不将整款应用宣传成零联网或零遥测。

不要上传聊天备份、设置导出、API 密钥、签名配置、个人录音或角色包。`.cyvoice` 角色导出包含参考录音和原文，不等于可以公开分享。故障日志应仅记录必要状态/时序，不记录密钥或实际聊天正文。
