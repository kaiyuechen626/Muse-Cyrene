## 源码与材料

应用源码 ZIP 和当前标签包含相同文件。公开源文件不包括语音 AAR、私钥、聊天、录音、模型或个人音色。准备脚本 prepare-local.ps1 / release-profile.json 仍只生成默认保持本地的候选；其中 publishAllowed=false 代表脚本无自动发布能力，不代表项目所有者此次手动发行请求未生效。历史 verification.json 的 hold / not executed 记录不改写，不能作为当前 GitHub 状态。

原 LICENSE 全文不变，NOTICE 原文保留并追加本地语音说明。0.1.0 的发布资料包作为原始材料原样附在 0.2.0 资料包中；新增语音许可及对应源码方向另附。语音原生库与 Cyrene Voice Studio 0.2.0 预览发行版逐字节一致，使用其相同上游源码包；应用自己的对应源码仍为 Muse 本标签及源码附件。

按所有者要求，本轮不继续处理继承的 Junrar / ML Kit 组合许可疑问，不把它们或完整运行时对应源码核对改成已经解决；沿用 0.1.0 披露。继承图像库的 16KB ELF 限制、长文等待及未执行的蓝牙/通话/全应用回归保持记录。发布不是额外法律授权或对所有设备的保证。
